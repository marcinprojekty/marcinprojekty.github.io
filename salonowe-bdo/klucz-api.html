Jak utworzyć klucz API w BDO

Klucz API łączy Twoje konto w BDO z aplikacją Salonowe BDO. Tworzysz go raz, zajmuje to około 5 minut. Potrzebne jest logowanie przez login.gov.pl (profil zaufany, e-dowód albo bankowość).

Rysunki to schematy – w BDO ekran może wyglądać trochę inaczej. Oficjalna instrukcja z prawdziwymi zrzutami ekranu: Instrukcja generowania kluczy API (BDO, PDF).

  1. Zaloguj się do BDO

    Wejdź na rejestr-bdo.mos.gov.pl i wybierz logowanie przez login.gov.pl.

  2. Wybierz swój salon

    Na liście podmiotów przy swojej firmie kliknij „Wybierz”. Klucz będzie działał tylko dla tego podmiotu.

  3. Otwórz zakładkę „API”

    W górnym menu, w części dotyczącej Twojej firmy, wybierz „API”. U części użytkowników jest ono w menu „Opcje” → „API”.

  4. Dodaj nowy klucz

    Kliknij przycisk dodania nowego klucza („+” albo „Nowa aplikacja”) i wypełnij dwa pola:

    • Nazwa aplikacji: Salonowe BDO
    • Callback URL: adres strony Salonowe BDO (pole jest wymagane, ale BDO go nie używa)

    Na koniec kliknij „Dodaj klucz API”.

  5. Skopiuj Client ID i Client Secret do aplikacji

    Nowy klucz pojawi się w tabeli. Skopiuj Client ID i Client Secret w całości (z myślnikami) i wklej je w aplikacji Salonowe BDO w kroku „1. Klucz API z BDO”, a potem kliknij „Sprawdź klucz w BDO”.

Warto wiedzieć

  • Klucz należy do osoby, która go utworzyła. Najprościej, gdy tworzy go właściciel salonu albo osoba, która w BDO ma dostęp do ewidencji i sprawozdań. Jeśli ta osoba straci dostęp do BDO salonu, utwórz nowy klucz i wklej go w aplikacji.
  • Nie wysyłaj klucza mailem, SMS-em ani na komunikatorze – nikomu, także nam. Wklejasz go tylko w aplikacji, która przechowuje go zaszyfrowanego. Nie podajesz nigdzie loginu ani hasła do BDO.
  • Klucz możesz w każdej chwili usunąć w tej samej tabeli w BDO (ikona usuwania → „Tak, usuń”). Aplikacja traci wtedy dostęp do BDO Twojego salonu.
  • Nie masz jeszcze wpisu do BDO? Najpierw potrzebny jest wpis do rejestru BDO – napisz do nas, podpowiemy, jak złożyć wniosek.
